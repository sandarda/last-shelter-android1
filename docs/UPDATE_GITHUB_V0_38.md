# Последнее убежище v0.38.0 — обновление

1. Полностью заменены девять фоновых изображений помещений: спальня, гостиная, смотровая, кухня, теплица, лаборатория, оружейная, мастерская и склад. Каждое — отдельный полноэкранный PNG 1536×864; изображения различаются по содержимому.
2. Герой остаётся узнаваемым постоянным персонажем в каждой комнате; на балконе поверх отдельной сцены также отображается портрет героя.
3. Выстрел и перезарядка теперь немедленно сохраняют состояние боезапаса. Сохранение/загрузка остальных игровых параметров и автосохранение сохранены.
4. Снайперское наведение остаётся ручным: касание/перетаскивание прицела, отдельная кнопка прицеливания, отдельный одиночный выстрел и ручная перезарядка.
5. Проверка проекта запускается командой `python tools/validate_project.py`.

## Ограничения проверки

В этой среде нет установленного Godot. Поэтому импорт ресурсов движком, запуск каждой сцены, фактическое поведение анимации выхода из воды/ходьбы, сенсорное управление на Android и APK export не подтверждены. Статический валидатор не является runtime-тестом. Перед публикацией APK обязательно выполнить Android build в GitHub Actions и проверить игру на устройстве.
