# Архитектура убежища — игровая схема v0.33

Убежище вырублено внутри скалы; игровой экран использует утверждённый полноэкранный срез. Три горизонтальные игровые плоскости привязаны к визуальным уровням на изображении.

## Верхний этаж — жилой и смотровой
- Спальня.
- Гостиная.
- Смотровая площадка с выходом в режим обороны балкона.

Связность: спальня ↔ гостиная ↔ смотровая; лестничная площадка доступна с левой стороны.

## Средний этаж — рабочий
- Мастерская.
- Оружейная.
- Кухня.

Связность: мастерская ↔ оружейная ↔ кухня; лестница соединяет уровень с верхним и нижним этажами.

## Нижний этаж — технический и запасы
- Склад.
- Теплица.
- Технический блок с очисткой воды.

Связность: склад ↔ теплица ↔ техблок.

## Перемещение

Геометрия движения задаётся отдельно для каждого этажа: нижний y=620, средний y=420, верхний y=220 в координатах игрового viewport 1536×864. Игрок перемещается по этажу касанием/мышью, клавиатурой или виртуальным джойстиком. При выборе лестницы герой сначала подходит к площадке, затем следует по последовательности точек винтовой лестницы; смена этажа происходит после завершения маршрута.

Интерактивная мебель запускает действие только после того, как герой дошёл до выбранной точки. Смотровая площадка запускает отдельную сцену обороны.

- Персонаж — мужчина средних лет в повседневной одежде, без рюкзака и тяжёлой брони; походка спокойная.
