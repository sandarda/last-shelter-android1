# Последнее убежище v0.39.0 — обновление

В этой версии интегрированы девять окончательно утверждённых пользователем интерьерных изображений. Спальня и гостиная сохранены в утверждённых вариантах; кухня, смотровая, теплица, лаборатория, оружейная, мастерская и склад заменены точными финальными изображениями, присланными/утверждёнными пользователем.

Все девять PNG — отдельные полноэкранные файлы 1536×864 (16:9), загружаются по собственным идентификаторам комнат через `art/rooms/*.png`. Код навигации по комнатам, истории, действия, сохранения, снайперская оборона, зомби и главный экран не переписывались.

## Сборка
1. Заменить содержимое репозитория файлами архива, включая `.github/workflows`.
2. Закоммитить в ветку `main`.
3. Запустить GitHub Actions workflow `Build Android APK`.
4. Скачать APK artifact после успешного завершения.

## Ограничения проверки
Локально проверены целостность ZIP, декодирование PNG, разрешения и уникальность девяти файлов, а также статические требования проекта. Godot в текущей среде не установлен, поэтому runtime-проверка комнат и APK export здесь не выполнялись. Их необходимо подтвердить GitHub Actions и запуском APK на Android.
