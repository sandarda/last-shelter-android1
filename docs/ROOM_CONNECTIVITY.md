# Проверка связности помещений — v0.33

На каждом из трёх этажей помещения связаны в линейную сеть коридоров, а лестничный узел соединяет этажи.

- Нижний: склад ↔ теплица ↔ техблок.
- Средний: мастерская ↔ оружейная ↔ кухня.
- Верхний: спальня ↔ гостиная ↔ смотровая.

При запуске `_validate_room_connectivity()` обходит граф каждой площадки и сообщает об изолированных комнатах. Навигационная геометрия строится отдельно на соответствующей высоте этажа. Переход между этажами выполняется анимированным маршрутом, а не мгновенным изменением индекса этажа.

Проверка графа и статические проверки не заменяют физический тест маршрутов в запущенном Godot.
