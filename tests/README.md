# Проверки проекта

Запуск статических проверок из корня проекта:

```bash
python3 tools/validate_project.py
```

Проверка контролирует наличие главной сцены и скрипта, соответствие путей, наличие восьми комнат, основных функций и референсного изображения.

Это не заменяет проверку в Godot: GDScript parser, игровой запуск, сенсорное управление и Android export требуют Godot 4.x и Android export templates.
